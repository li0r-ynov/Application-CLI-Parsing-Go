# TP-Go-Reloaded

Un outil d'autocorrection de texte en Go, un programme qui lit un fichier, applique toutes les règles de transformation, puis écrit le résultat dans un second fichier.

# Fonctionnalités

- UP
- LOW
- CAP
- HEX
- BIN
- PONCTUATION
- APOSTROPHES
- A --> AN
- TEST

# Technologies utilisées

- Langage : Golang, Go est un langage de programmation compilé et concurrent inspiré de C et Pascal. Il a été développé par Google à partir d’un concept initial de Robert Griesemer, Rob Pike et Ken Thompson.

- Outils : VS Code, GitHub, Google, Youtube, Doc officielle de Go 

# Le dépôt

git clone https://github.com/li0r-ynov/Application-CLI-Parsing-Go

# Installation

Étapes :
-Installer Vs Code sur votre PC
-Installer le langage de Programmation Golang dans VS Code
-Copier l'adresse du dépot GitHub 
-Ouvrir l'Explorateur de fichiers
-Sélectionner un dossier où placer le projet Go-Reloaded
-Aller dans la barre d'adresse et écrire "cmd"
-Écrire la commande suivante "git clone <URL_DU_DEPOT>"
-Retourner dans votre dossier, et vérifier que le noveau dossier est apparu
-Ouvrir VS Code et aller dans l'onglet "file"
-Cliquer sur "open folder"
-Sélectionner le dossier que vous venez de créer
